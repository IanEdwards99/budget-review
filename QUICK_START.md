# Quick Start

## Windows

1. Install Python 3.11 or newer from <https://www.python.org/downloads/>.
2. Download or clone this repository.
3. Double-click `start_windows.bat`.
4. The app opens at <http://127.0.0.1:5057>.
5. Drop in the ABN AMRO and Wise exports and click `Generate review`.

The first run installs dependencies. Later runs are faster.

## Mac / Linux

Open a terminal in this folder:

```sh
chmod +x start_macos_linux.sh
./start_macos_linux.sh
```
